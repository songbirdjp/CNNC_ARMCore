# AFC板RS422通讯协议

## 1 帧格式定义

### 1.1 硬件和方向定义

由BGM ARM IO板到AFC板的数据称为下行数据；

由AFC板到BGM ARM IO板的数据称为上行数据；

**下行：**500000Bits/s；字长8bits；无校验位；1停止位

**上行：**500000Bits/s；字长8bits；无校验位；1停止位

### 1.2 统一帧格式

| header | count | data len | data | crc32 |

字节序: LSB first            比特序: LSB first

| 字段         | 长度    | 描述                                                         |
| ------------ | ------- | ------------------------------------------------------------ |
| **header**   | 2 bytes | 固定为 0x55 0xAA                                             |
| **count**    | 2 bytes | 当前帧序号，从 0 开始，溢出时归零继续计数                    |
| **data len** | 2 bytes | 数据长度                                                     |
| **data**     | 变长    | 数据内容，根据 **data len** 字段的值来决定长度，具体内容见1.4 |
| **crc32**    | 4 bytes | 数据校验值，采用 CRC32 算法（polynomial=0x04C11DB7, init=0xFFFFFFFF, xor=0xFFFFFFFF），计算时包含 **count**、**data len**、**data** 三个字段 |

### 1.3 数据格式

| 字段    | 描述                         | 位数    | 取值范围                            |
| ------- | ---------------------------- | ------- | ----------------------------------- |
| **id**  | 标识访问的总线上设备的ID标号 | 7 bits  | 0~127, 其中0为广播，1~127为具体设备 |
| **ack** | 表示是否需要应答             | 1 bit   | 0：不需要，1：需要                  |
| type    | 帧类型                       | 1 Byte  | --                                  |
| len     | 数据帧的总长度               | 2 Bytes | --                                  |
| data    | 数据内容                     | n Bytes | n 与 帧长度一致                     |
